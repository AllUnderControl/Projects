I developed a BLDC control system for an electric bicycle using an STM32-family microcontroller, programmed within the STM32CubeIDE. The system utilized a six-step commutation algorithm to drive the motor, with a PI controller implemented current control.

While the project made significant progress, it was ultimately put on hold due to a lack of funding. Consequently, a formal presentation was not finalized. However, photographs documenting the lab setup and hardware implementation are available.
