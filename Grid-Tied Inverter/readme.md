This was the final project for the Analog and Digital Control course. After some improvements, the project was submitted to a conference and will later be available on IEEE Xplore. The paper link will be posted here once available.

The project consists of a grid-side current control for a three-phase inverter using an LCL filter. By using the rotating reference frame (α-β), the system was decoupled into two separate subsystems, discretized, and included a one-step computational delay. To design the controller, a resonant controller was applied. To reduce the number of sensors, a full-state observer was implemented. Furthermore, to compensate for parametric variations, a disturbance observer based on the exact discrete-time method was introduced. To ensure robustness across all scenarios, a genetic algorithm (GA) was used to calculate the sub-optimal gains for both the controller and the observers. The choice of the GA over classical methods, such as LMI approaches, was due to its flexible objective function, which can be tailored to describe the system's desired closed-loop response.
